# 批处理与停滞

批处理让配方机器一次处理多份配方。批量 B 由四个维度共同决定：

1. 物品输入是否足够。
2. 流体输入是否足够。
3. 输出槽或储罐能否装下最坏情况产出。
4. 当前能量能否支撑本周期。

处理开始后会锁定 B 与最大进度；中途取走部分输入不会改变本周期的 B。输出采用快照-模拟-提交，失败会回滚。

## 停滞

* 缺能、断信号、输出满：保留进度，等待恢复。
* 输入消失或配方失配：处理型与配方型机器进度归零；效果型机器同样归零。
* 效果型机器（冷却器、信标模拟机等）没有配方槽，输入消失时进度作废。

批量越大，单周期总能耗越高，但单件处理时间不变。升级与批处理的组合详见[升级](upgrades.md)。
