# 内容介绍

科能工程（Kenergy Engineering Retechnicalized）是 Technical Engineering 4 的重制分支，一个做加工与自动化基建的科技模组。
引擎发电，线缆送电，机器加工，管道和频道把产物搬走，批量处理把产量堆起来——整条线都在模组里闭环。
这里只讲有哪些内容；配方、耗时和数值请看游戏内指南或配方查看器。

运行环境：Minecraft 1.21.1 / NeoForge

## 加工机器

八台，配方逻辑、批量处理和停摆规则完全一致，学会一台就会全部。一轮可以跑多份配方，输入、输出空间或能量不够就会等。

| 机器 | 作用 |
|---|---|
| 熔炼机 | 用能量跑原版熔炉类配方，装升级可切到高炉或烟熏 |
| 粉碎机 | 把矿物和金属磨成粉增产，带额外产出 |
| 压缩机 | 配模具压出板、杆、齿轮、线等形状，模具不会被消耗 |
| 精炼机 | 在物品与流体之间互相精炼，把材料往高级推进 |
| 感应炉 | 多种原料一起合成合金 |
| 灵能处理器 | 两格原料按固定配对合成稀缺材料 |
| 祛魔机 | 把附魔从工具转到书或空白工具上，附魔值折成液态经验 |
| 物质结晶器 | 消耗催化剂，持续凝聚奇异物质流体 |

## 环境与作业机器

七台，没有配方槽，靠自身位置和朝向工作。缺能、红石切断、输出满时进度会保留；输入没了进度作废。

| 机器 | 作用 |
|---|---|
| 冷却器 | 贴着机器正面放，缩短那台机器的加工耗时，消耗冷却剂 |
| 信标模拟机 | 给周围一大片玩家持续药水效果，需要一件药水物品当模板 |
| 生物啃噬者 | 用武器槽里的武器清理机器背面的生物 |
| 采矿场 | 一路向下挖穿所在区块直到维度底，可切标准或极速扫描 |
| 农场管理机 | 接管背面的农田，自动补种并采收成熟作物 |
| 方块破坏器 | 沿正面破坏方块，消耗工具耐久 |
| 方块成型器 | 沿正面放置方块，候选栏会持续补料 |

## 引擎

四台的能量面默认输出，主动把电推给相邻机器或线缆。

| 机器 | 作用 |
|---|---|
| 萃取引擎 | 烧普通燃料发电 |
| 金属引擎 | 烧金属锭发电 |
| 生物质引擎 | 烧树叶、原木这类植物发电 |
| 光合引擎 | 靠天空光照发电，需要露天晴天 |

## 能量与传输

| 设备 | 作用 |
|---|---|
| 能量单元 | 储能缓冲，顺便给电池类物品充放电 |
| 能量模块 | 随身电池，自动给身上和饰品槽里的用电设备充电 |
| 能量线缆 | 四档由细到粗，自动连接相邻线缆与机器，可在水中放置 |
| 物品管道 | 普通、白名单、黑名单三种，只有设为主动抽取的一侧才会进机器拿东西 |
| 扳手 | 旋转机器朝向，潜行右键拆下机器并带走内容与升级 |

## 频道系统

跨机器、跨维度的共享存储，分物品、流体、能量三种，同名不同类型的频道互不相通。用频道连接器把机器接到频道上，频道方块本身也能当普通容器接入。

| 频道 | 作用 |
|---|---|
| 物品频道 | 共享库存，接入的机器越多，同一件物品能攒的量越大 |
| 流体频道 | 共享储罐 |
| 能量频道 | 共享储能 |

## 面配置与升级

机器六个面各自独立设置输入、输出、被动或关闭，默认双向；红石控制也在同一个界面里。机器停摆时先查面权限，再查输入输出余量，最后查红石和能量。范围机器还能开关工作范围线框，采矿与破坏可以按工具附魔结算。

升级件放机器界面的升级槽，不支持的会被直接拒收。

| 升级件 | 作用 |
|---|---|
| 充能组件 | 提速提功率，附带批量 |
| 增强组件 | 提速提功率，幅度较缓 |
| 潜影组件 | 提速提功率最猛、批量加成最大，末地城宝箱里能翻到 |
| 光合供能抑制 | 晴天白昼露天时机器自己供一点电，代价是耗时变长 |
| 作用范围扩展 | 扩大范围机器的作用半径 |
| 矿物专业冶炼 | 熔炼机切到高炉，与烟熏互斥 |
| 食物专业烟熏 | 熔炼机切到烟熏，与高炉互斥 |
| 知识储备扩充 | 熔炼机按熔炼时长副产液态经验 |
| 矿物探测仪器 | 采矿场只采矿物 |
| 地下冻土开采 | 采矿场产出改成冰 |
| 地幔深层钻井 | 采矿场产出改成岩浆 |
| 药水效能榨取 | 信标模拟机的效果等级加一 |
| 星辉能量传输 | 占位内容，装上暂时没有效果 |

## 材料与产物

| 类别 | 内容 |
|---|---|
| 金属与矿物 | 锡、镍、充能锡、叶绿、蘑菇，加上常见的铁铜金与宝石类材料 |
| 加工形状 | 粉、板、杆、齿轮、线，以及粗料与储存块 |
| 模具 | 九种，决定压缩机压出什么形状 |
| 流体 | 液态经验、蜂蜜、蜂王浆、香辣蜂王浆、奇异物质，都能用桶取走 |
| 组装件 | 红石元件与芯片、液压组件、琉璃、靛青 |

所有材料都按通用标签登记，其他模组往标签里加成员就能被机器认。

## 兼容的模组

| 模组 | 支持内容 |
|---|---|
| JEI（推荐） | 每台机器都有配方页，熔炼机分熔炼、高炉、烟熏三页，另有引擎燃料页和冷却剂页 |
| EMI | 机器页与燃料页已经做好，仍在实机验证中 |
| Jade | 准星对准就显示频道接入状态和管道是否处于主动抽取 |
| GuideME（可选） | 装了才出现《科能工程指南》，不装照常运行 |
| Curios API（可选） | 能量模块可以走饰品槽充电 |
| AE2 生态 | AE2 不是前置，机器接口按物流模组的读写习惯实现，样板供应器之类的设备能对接。装了 AE2 或其附属（ExtendedAE、Data Energistics、AE2 Crystal Science 等）时，它们的水晶还能进粉碎机磨成该模组自己的粉 |
| Ender IO、Ender IO: Evolution、Mekanism、Immersive Engineering、All the Ores、Allthemodium、NEO ECO AE Extension | 粉碎机、压缩机和感应炉承接它们的材料与矿石加工链，缺料的配方整条消失，不会显示跑不通的配方 |

## 游戏内指南

《科能工程指南》需要 GuideME，从第一台机器怎么供电，到面配置和批量停滞的判定顺序，都写在同一本书里。
